# 链上与在线数据采集会话SOP

## 1. 文件目的

本程序规定公共链节点、第三方RPC/API、区块浏览器及经授权在线来源的单次采集如何启动、执行、记录、失败、复核和封存。目标是取得可定位的原始响应和足够上下文，使第二人员能够判断“从什么来源、在什么时点、以什么请求得到哪些字节”。

本程序当前仅用于公开数据研究和批准的模拟演练，尚未获得真实案件运行授权。技术上能够访问不等于有权访问；授权不清时必须停止。

## 2. 适用范围与禁止事项

### 2.1 纳入

- 自建或受控节点的只读协议/RPC采集；
- 合规批准的第三方RPC/API和区块浏览器页面/API；
- 公开规范、公开实现及公共链原始对象；
- 授权平台导出、在线页面和接口响应；
- 因链重组、限流、分页、超时或来源冲突产生的失败记录。

### 2.2 禁止

- 绕过身份验证、访问控制、验证码、付费边界或技术限制；
- 使用未经批准的账户、密钥、代理、抓包或自动化；
- 输入、导出或保存私钥、助记词、口令、令牌和无关个人数据；
- 发送交易、签名、广播、冻结、控制、转移或处置资产；
- 把页面截图替代原始响应，把单一浏览器结果称为独立验证；
- 采集过程中覆盖原文件、删除失败请求或事后伪造采集时间。

## 3. 角色与职责分离

|角色|职责|停止权限|
|---|---|---|
|采集负责人|批准会话计划、来源、工具和风险|任何前提失败|
|授权核验人|核对对象、动作、期限、来源和限制|授权缺失、过期或歧义|
|采集执行人|按冻结计划操作并记录实际情况|工具、来源、同步或范围漂移|
|第二人员/见证人|在规定场景见证或独立复核P0步骤|身份不独立或记录不完整|
|证据管理员|接收原始对象、核对清单并封存|哈希、数量或位置不一致|
|质量负责人|检查偏离、缺陷、抽样和关闭证据|重大差异或重复缺陷|

同一人可以在模拟研究中兼任采集负责人和执行人，但不能同时形成“独立复核通过”结论。

## 4. 会话状态

```text
planned -> authorized -> running -> captured -> verified -> sealed
   \          \           \          \          \
  blocked     blocked     interrupted blocked    disputed
```

|状态|含义|
|---|---|
|`planned`|问题、范围和来源已拟定|
|`authorized`|授权核验与采集计划获批|
|`running`|会话已开始且原始记录在生成|
|`captured`|请求完成并登记对象|
|`verified`|规定的哈希、字段和第二人员检查完成|
|`sealed`|原始对象及记录已移交受控存储|
|`interrupted`|发生中断且不能无歧义续接|
|`blocked`|前提失败或缺关键证据|
|`disputed`|来源、哈希、时间或人员记录存在争议|

未经过`authorized`不得进入`running`；`verified`不等于来源真实或方法有效。

## 5. 详细控制要求

|控制ID|控制主题|强制要求|停止/拒绝条件|
|---|---|---|---|
|SOP-002-C001|采集会话编号|启动前生成唯一会话ID并关联案件/项目、计划、授权和包ID|编号重复或无法关联任务|
|SOP-002-C002|人员与见证|记录实际执行、授权核验、见证/复核人员和独立性；规定双人场景不得缺席|共享账号、人员未知或见证仅事后签字|
|SOP-002-C003|时间时区|记录开始、结束、每次请求、源时间、时区、精度、时钟源和偏差|关键时间无时区或系统时钟异常未处置|
|SOP-002-C004|工作站身份|记录受控资产ID、系统版本、启动状态、隔离/安全基线和时间|未批准设备或环境状态不明|
|SOP-002-C005|网络位置|记录受控区域、网络出口、代理/VPN状态、DNS及适用的公网出口标识|越过批准网络边界或代理漂移|
|SOP-002-C006|节点身份|记录链、网络、节点/端点、控制方、客户端标识、能力和来源类型|链/网络或端点控制方不明|
|SOP-002-C007|客户端版本|记录节点客户端、采集工具、库、浏览器或API版本/构建及获取位置|只能得到产品名且版本影响结果|
|SOP-002-C008|同步状态|记录高度、目标高度/头高度、同步标志、最终性/确认边界和测量时间|落后或状态未知却要求最新完整数据|
|SOP-002-C009|请求参数|原样保存方法、端点、参数、区块标识、分页、过滤、请求体和顺序|参数泄密、范围越权或漏页不可判断|
|SOP-002-C010|原始响应|保存状态码、头和响应精确字节；解析、脱敏和美化另建派生对象|只保留显示结果或响应被隐式转换|
|SOP-002-C011|原始区块|能取得协议原始字节时单独保存并记录编码和边界；无法取得须说明|宣称字节级核验但无原始字节|
|SOP-002-C012|页面快照|页面采集保存URL、重定向、页面/资源或截图、可见时间和限制|以截图替代底层数据或遗漏动态加载说明|
|SOP-002-C013|TLS信息|对HTTPS来源记录最终主机、协议、证书主题/指纹和验证结果；不宣称完整网络取证|证书错误被绕过或主机与授权来源不符|
|SOP-002-C014|录像索引|要求录像时记录文件ID、起止时间、哈希和步骤锚点；不适用要有理由|录像应有但缺失、不可读或时间无法对齐|
|SOP-002-C015|哈希|原始对象入库前计算SHA-256、字节数和范围；第二人员按计划复算|同一对象哈希不一致或范围不明|
|SOP-002-C016|错误重试|每次失败、等待、重试原因、退避、参数变化和结果分别记录|重试覆盖失败或无上限重试改变来源状态|
|SOP-002-C017|链重组|记录高度/哈希快照和最终性；发现重组保留前后对象并标记受影响结果|覆盖旧观察或把临时状态写成最终|
|SOP-002-C018|会话中断|中断时立即封存已取得对象并记录最后完成步骤；续采创建新会话或明确子会话|时间/参数/来源无法连续却强行续接|
|SOP-002-C019|独立复核|第二人员核对授权、来源、P0对象哈希、请求和关键字段；记录实际重算|执行人与复核人为同一人或只看摘要|
|SOP-002-C020|封存|按清单向证据管理员移交对象、日志、环境和异常；双方核对数量与根/容器哈希|未接收、哈希不一致或工作副本未分离|

上述控制目前均为`not_implemented`；表单和端到端模拟完成前不得用于真实案件。

## 6. 会话前准备

### 6.1 采集计划

采集负责人必须在运行前冻结：

- 明确问题及所需原始对象；
- 链、网络、区块高度/哈希、交易ID、地址或事件范围；
- 来源优先级及独立性判断；
- 授权依据、允许动作、期限和数据最小化；
- 方法、工具、版本、请求和分页策略；
- 最终性/确认要求和会话时窗；
- 正常、失败、冲突、限流和重组分支；
- P0字段及第二人员复核范围；
- 预期目录、命名和封存位置。

不得使用“采集所有相关数据”作为范围。

### 6.2 环境检查

- [ ] 工作站资产、系统和当前时间已记录；
- [ ] 自动更新、后台同步及可能改写输出的功能已评估；
- [ ] 存储空间、只读原始区和临时目录已确认；
- [ ] 网络、代理、DNS和出口符合批准范围；
- [ ] 工具、客户端、证书和依赖版本已固定；
- [ ] 账户/令牌来自批准密钥管理，不写入日志；
- [ ] 录像要求和隐私遮挡已确定；
- [ ] 原始、派生和屏幕记录目录已分离；
- [ ] 紧急停止与联系人已明确。

### 6.3 来源检查

|来源|最低前置|独立性限制|
|---|---|---|
|自建节点|控制方、客户端、网络、同步状态、数据目录状态|同一软件缺陷仍可能影响多个节点|
|第三方RPC|供应商、端点、合同/公开条件、地区、限流、版本|多个端点可能共享上游|
|浏览器API|运营方、API版本、分页、缓存、数据字段定义|页面和API可能同一后端|
|网页|最终URL、动态加载、区域/登录状态、访问时间|截图不证明底层协议事实|
|委托方平台|书面授权、账户、导出功能、时间范围|内容由提供方控制需外部核验|

## 7. 标准执行流程

### 7.1 启动

1. 执行人与第二人员核对会话ID、计划版本和授权状态。
2. 记录工作站、网络、时间、工具和来源基线。
3. 创建会话目录和追加式操作记录。
4. 对将运行的请求模板做秘密扫描；令牌只通过安全引用注入。
5. 将状态从`authorized`改为`running`并记录实际开始时间。

### 7.2 请求与捕获

每次请求至少生成：

- `request_id`和顺序号；
- 方法、端点、参数、请求体哈希；
- 发送、首字节、完成时间（可取得时）；
- HTTP/RPC状态、响应头和原始响应对象ID；
- 分页游标、返回数量和下一页决定；
- 重试/限流信息；
- 解析状态但不在原始对象上写回。

二进制响应直接保存字节。文本响应保存实际编码字节，并在派生记录中解析编码；不得在保存前自动格式化JSON。

### 7.3 原始区块与关键对象

针对区块/交易任务：

1. 优先按方法要求取得原始字节或无损十六进制；
2. 记录链、网络、高度、请求块哈希和来源块哈希；
3. 保存请求响应和解码后的字节对象为不同对象；
4. 计算字节对象SHA-256；
5. 解析结果必须引用原始对象和方法版本；
6. 如仅能取得标准化字段，明确“不支持字节级复算”。

### 7.4 页面与录像

页面采集至少记录最终URL、重定向链、可见时间、浏览器版本、登录/区域状态、页面快照对象和关键元素定位。录像只是过程辅助：

- 录像不得暴露令牌、密钥或无关个人信息；
- 录像索引对应结构化步骤；
- 页面滚动或点击不替代请求参数和原始对象；
- 无法保存动态资源时声明限制。

### 7.5 结束

1. 停止新请求并记录实际结束时间。
2. 清点请求数、成功数、失败数、重试数、页数和对象数。
3. 计算全部原始对象哈希和字节数。
4. 登记未取得、冲突、临时状态和重组影响。
5. 生成采集记录和证据对象登记。
6. 切换为`captured`，等待独立复核。

## 8. 分页、限流和重试

### 8.1 分页完整性

- 冻结排序字段和方向；
- 记录每页请求、游标、首末对象和数量；
- 检测重复、间隙和游标循环；
- 来源数据在分页期间可能变化时记录快照能力或时间边界；
- 无法证明完整分页时只表述为“取得的页面集合”，不得表述全量。

### 8.2 重试规则

|错误|默认动作|禁止|
|---|---|---|
|超时/网络断开|记录失败后有限次数退避重试|删除失败或无限重试|
|429限流|遵守服务端等待提示并记录|并发绕过限流|
|4xx授权/参数|停止并核对授权与请求|反复猜测账户或参数|
|5xx服务错误|有限重试并考虑第二来源|把错误页当空结果|
|响应解析失败|保留原始字节并停止该解析|美化或修复后覆盖原响应|
|哈希/内容冲突|保存各版本并升级|选一个“看起来正确”的覆盖|

任何参数、来源或工具变化均创建新的请求记录；若变化影响会话可比性，创建新会话。

## 9. 链重组与动态状态

- 使用区块哈希而非仅高度标识冻结对象；
- 记录采集时的头高度、目标块高度和确认/最终性；
- 对账户余额、mempool、确认数、标签等动态字段记录观察时点；
- 观察到同高度不同哈希时创建冲突和重组记录；
- 重组后重新采集生成新对象，不覆盖旧对象；
- 报告说明结论基于哪个冻结快照；
- 方法未验证相应最终性规则时输出`unable_to_determine`或限制。

## 10. 中断与异常处置

|异常|立即动作|恢复条件|
|---|---|---|
|工作站时间跳变|停止请求、记录前后时间和日志|重新确认时钟并新建子会话|
|网络出口变化|停止并记录实际出口|授权核验后新会话|
|工具崩溃|保存崩溃日志和已得对象|确认原始对象未改写|
|磁盘不足|停止写入、封存当前对象|换批准介质并作为移交事件|
|秘密进入日志|停止、隔离、轮换秘密并报告|脱敏派生副本获批|
|来源内容变化|保存前后响应|明确动态性或冻结机制|
|权限提示异常|立即停止|书面澄清授权|
|发现可能需要主动交易|停止并升级合规|本SOP不允许恢复该动作|

不得通过修改系统时间、回填日志或删除坏对象来“修复”会话。

## 11. 独立复核与关闭

第二人员从只读副本执行：

1. 核对授权、范围、链/网络和来源控制方；
2. 复算全部P0原始对象哈希与字节数；
3. 抽查请求参数与实际响应对象；
4. 复算关键区块/交易标识或按方法检查协议字段；
5. 检查分页、重试、失败和中断是否完整；
6. 检查来源独立性、同步状态和最终性边界；
7. 核对原始、派生、页面和录像对象区分；
8. 登记差异、影响、处置和结论。

只有以下条件满足才能转`verified`：

- 授权和来源边界明确；
- P0对象哈希、字节数和标识一致；
- 失败、重试、中断、重组和缺失均有记录；
- P0差异关闭；
- 复核人身份独立。

随后证据管理员依据清单接收、核验和封存；双方回执后状态转`sealed`。

## 12. 执行检查点与停止条件

### CP-1 授权门

- [ ] 对象、来源、动作、期限和限制有书面依据；
- [ ] 公开数据仍已核对服务条款、访问方式和数据最小化；
- [ ] 账户、密钥、代理和网络均在批准范围；
- **停止**：任何授权歧义、绕过控制或主动资产动作。

### CP-2 环境门

- [ ] 工作站、时间、网络、工具和节点身份已冻结；
- [ ] 原始区、派生区和秘密管理已分离；
- [ ] 同步/最终性满足计划；
- **停止**：环境身份不明、时钟异常、节点落后或未批准更新。

### CP-3 捕获门

- [ ] 每个请求有参数、时间、状态和原始响应；
- [ ] 分页、重试、错误和中断未被覆盖；
- [ ] 原始字节先保存再解析；
- **停止**：原始对象改写、漏页不可判断或来源冲突未保留。

### CP-4 完整性门

- [ ] 全部原始对象有字节数和SHA-256；
- [ ] P0对象由第二人员复算；
- [ ] 父对象、方法、工具和参数引用完整；
- **停止**：哈希不一致、对象缺失、范围不明。

### CP-5 封存门

- [ ] 会话清单、异常、复核和对象已交接；
- [ ] 接收方独立核对数量和容器/包根哈希；
- [ ] 原始区与工作副本已分离；
- **停止**：无回执、传输不一致或P0差异未关闭。

## 13. 最低记录集

- 会话计划与授权核验；
- 采集会话表（FRM-003待实测）；
- 工作站、网络、节点、工具和时钟环境记录；
- 原始请求、响应、区块/文件、页面及录像索引；
- 对象清单、字节数、哈希和父引用；
- 分页、失败、重试、中断、重组和偏离；
- 独立复核、差异、决定和关闭证据；
- 封存清单、移交事件和接收回执。
