# 分析、假设与独立复核SOP

## 1. 文件目的

本程序规定如何从已封存的原始对象提出可回答的分析问题，冻结数据集、方法、工具和规则，生成候选结果，登记假设与反向证据，并由第二人员独立复算后形成受限结论。

核心边界：

- 链上字段是观察或按方法解析的事实；
- 图路径、聚类、标签和评分是规则或统计推断；
- 地址与自然人/企业的对应需要合法外部证据和适当主体综合判断；
- 技术分析不得替代法律定性、资产处置决定或司法鉴定资质。

本程序尚未授权用于真实案件。

## 2. 适用范围与排除

### 2.1 纳入

- 区块、交易、输入输出、账户状态、回执和事件日志的确定性重建；
- 冻结数据集上的金额、手续费、路径和图关系计算；
- 受控标签、规则、启发式和模型的候选结果；
- 链上与经授权链下资料的可追溯比较；
- 独立复核、分歧处理、结论等级和限制。

### 2.2 排除

- 未经授权扩展主体、链、时间、账户或外部数据范围；
- 使用未经验证的混币穿透、归属识别或风险评分作确定结论；
- 自动生成违法属性、主观意图、受益所有人或法律责任；
- 交易、签名、账户控制、冻结解冻、兑付、估值和处置；
- 为得到预期结论而更换规则、阈值、数据源或删除反例；
- 以图的视觉邻近替代路径或金额计算。

## 3. 角色与独立性

|角色|职责|不得单独完成|
|---|---|---|
|分析负责人|批准问题、方法、数据集和复核计划|批准自己全部P0结果|
|分析执行人|按冻结快照运行并登记候选、异常和限制|改阈值后沿用原运行ID|
|数据管理员|生成只读分析快照并核对manifest|参与选择性删除反向证据|
|规则/方法负责人|维护规则语义、适用范围和验证状态|把未验证规则授权生产|
|独立复核人|从冻结输入独立重算P0字段和抽样结果|直接读取执行人结论充当复算|
|质量负责人|检查抽样、差异、偏离和关闭证据|豁免未解释P0差异|
|结论批准人|接受限制和残余风险|在问题越权或证据不足时强行出结论|

资源不足不能职责分离时，结果保持`candidate`或`blocked`。

## 4. 分析状态与输出层级

### 4.1 状态

```text
planned -> frozen -> running -> candidate -> reviewed -> approved_for_reporting
   \         \          \           \           \
  blocked    void       failed      disputed     restricted
```

- `frozen`：问题、输入、方法、工具、参数、规则和判定已固定；
- `candidate`：执行完成但尚未经独立复核；
- `reviewed`：复核完成，不等于可对外发布；
- `approved_for_reporting`：仅允许在批准范围和结论等级内进入报告；
- 任一输入或规则实质变化必须生成新运行ID。

### 4.2 信息层级

|层级|名称|例子|表达模板|
|---|---|---|---|
|F1|来源观察|原始响应包含某字段|“对象X在位置Y记录为Z”|
|F2|标准化事实|按方法解析出交易ID|“按方法M/V解析为Z”|
|C1|确定性计算|输入输出求和、路径枚举|“在冻结集合D上按算法A结果为Z”|
|R1|规则推断|启发式命中|“规则R命中，不能单独证明主体归属”|
|S1|统计推断|模型评分|“模型M在已验证范围内输出Z”|
|H1|人工判断|采纳/排除候选|“复核人基于证据集合决定Z并受限于L”|

不同层级不得在导出或报告中静默合并。

## 5. 详细控制要求

|控制ID|控制主题|强制要求|停止/拒绝条件|
|---|---|---|---|
|SOP-003-C001|分析问题|写成可验证问题并明确对象、链、时间、字段、输出和不回答事项|“全面追踪”“识别所有关联方”等无边界问题|
|SOP-003-C002|数据集版本|使用只读manifest、包根哈希/快照ID、对象范围、高度/时间边界和缺失说明|数据仍变化或无法重建同一输入|
|SOP-003-C003|工具版本|记录工具ID、版本/构建、验证状态、运行环境和允许用途|工具未验证或超出允许范围|
|SOP-003-C004|参数|运行前冻结查询、深度、方向、资产、阈值、时间、排序、舍入及资源限制|看到结果后修改且沿用原运行|
|SOP-003-C005|规则版本|每条规则有ID、版本、语义、前提、反例、验证状态和输出层级|规则来源不明或验证范围不符|
|SOP-003-C006|证据引用|关键输入和结果引用对象ID、字段/偏移、父关系及采集会话|只引用截图、标签名称或界面结果|
|SOP-003-C007|候选结果|机器和人工候选先标`candidate`并记录生成条件、排序和去重|未经复核直接作为结论|
|SOP-003-C008|假设登记|命题、支持证据、反向证据、可证伪条件、状态和责任人独立登记|把假设写成事实或无可证伪条件|
|SOP-003-C009|替代解释|每个主体归属、资金路径或行为解释至少评价合理替代解释|只保留支持预期叙事的解释|
|SOP-003-C010|负向证据|未命中、冲突、无交易、路径中断和标签相反等负向证据纳入同一快照|删除空结果或反向证据|
|SOP-003-C011|人工排除|排除候选须记录人员、权限、证据、规则、理由、时间和影响|仅写“专家判断”或批量无理由排除|
|SOP-003-C012|计算复核|P0计算由第二实现/人员从父对象重算并比较中间量与结果|只复读执行输出或只看最终图|
|SOP-003-C013|金额守恒|按资产、单位和协议语义核对输入、输出、费用、铸造、销毁及未知项|跨资产直接相加、浮点误差或未知项被填0|
|SOP-003-C014|图谱过滤|记录节点/边纳入、排除、聚合、截断、时间/深度和标签过滤|图未显示即当作不存在或隐藏过滤|
|SOP-003-C015|复核抽样|冻结总体、分层、样本量、选择方法/随机种子和扩大触发|方便抽样或绕开高风险对象|
|SOP-003-C016|全量复核条件|P0结果、低样本、高风险、规则变更、差异聚集和外部发布触发全量复核|触发后仍以抽样通过替代|
|SOP-003-C017|分歧处理|执行人与复核人分别保留意见、证据和影响，由第三角色裁决或输出争议|强制改成一致或删除少数意见|
|SOP-003-C018|结论等级|只使用事实确认、受限计算、规则候选、统计候选、无法判断五级|规则/评分直接升级为身份或违法确定结论|
|SOP-003-C019|限制|列出未覆盖链、时期、来源、协议、字段、规则、最终性和外部证据|用通用免责声明替代具体限制|
|SOP-003-C020|冻结快照|复核和报告引用同一不可变快照；任何修订创建新版本和影响分析|复核中输入继续变化或报告换了数据集|

所有控制当前仍为`not_implemented`，两次完整模拟前不得改变。

## 6. 分析启动与冻结

### 6.1 问题分解

将委托/研究问题拆为最小任务：

- 对象是否存在并能否固定；
- 某字段按协议/方法如何解析；
- 某交易的输入、输出、事件和费用如何重建；
- 在限定快照内是否存在满足明确定义的路径；
- 某规则是否命中以及反例是什么；
- 哪些问题因数据、方法或授权不足无法判断。

每个任务指定P0字段、预期输出、拒绝条件和报告层级。

### 6.2 冻结清单

运行前记录：

- `analysis_run_id`及问题版本；
- 输入包ID、manifest和根哈希；
- 链/网络、高度/时间、最终性和缺失；
- 方法、工具、环境、规则及版本；
- 参数、阈值、排序、随机种子和资源上限；
- 预期中间量和输出；
- 正常、边界、冲突、恶意和无法判断分支；
- 复核总体、抽样和全量触发；
- 允许的结论等级。

冻结后变更任何P0项，原运行标`void`或保留为历史，创建新运行。

## 7. 标准分析流程

### 7.1 输入校验

1. 验证证据包Schema、对象哈希、父引用和根哈希。
2. 核对采集会话已封存且授权覆盖分析动作。
3. 检查链、网络、协议时期和最终性。
4. 对P0输入由分析执行人复算标识/字段。
5. 建立只读快照和受控输出目录。
6. 缺口触发拒绝或缩小问题，不得默认补齐。

### 7.2 确定性分析

- 从原始对象解析并保存字段级来源定位；
- 金额使用最小单位整数字符串；
- 记录输入输出集合、顺序、去重和单位；
- 输出中间表、异常和守恒差异；
- 路径枚举固定方向、深度、时间和资产；
- 结果超过资源上限时输出截断边界而非“全量”。

### 7.3 规则与模型

每条规则/模型运行单独保存：

- 版本和验证范围；
- 输入对象及特征来源；
- 参数/阈值；
- 命中与未命中；
- 已知假阳性/假阴性；
- 反例和替代解释；
- 输出层级和禁止表述；
- 实际运行状态。

供应商“风险标签”“实体名称”属于外部主张，须登记来源、许可、日期、作用域和独立核验状态。

### 7.4 候选与人工决定

机器输出先进入候选区。人工可：

- 接受候选进入复核；
- 排除并给出对象级理由；
- 合并/拆分但须保留原候选和规则；
- 标记冲突或无法判断；
- 请求新数据，但新采集必须另走授权和采集SOP。

禁止人工直接改写机器输出文件或删除反向证据。

## 8. 假设、替代解释与负向证据

### 8.1 假设卡

|字段|要求|
|---|---|
|`hypothesis_id`|稳定ID|
|命题|单一、可证伪|
|层级|R1、S1或H1|
|支持证据|对象级引用|
|反向证据|同等可见|
|替代解释|至少列出并评价合理选项|
|可证伪条件|什么新证据会改变状态|
|状态|open、supported_limited、rejected、conflicted、unable_to_determine|
|限制|适用链、时期、方法和来源|

### 8.2 典型替代解释

|表面现象|必须考虑的替代解释|
|---|---|
|共同输入|托管、批处理、协作交易或协议机制|
|短时间连续转账|自动化、交易所归集、套利或普通批处理|
|地址收到风险标签资金|间接接触、服务平台中转、标签错误|
|金额接近|手续费、舍入、拆分合并、巧合或跨资产换算|
|路径中断|隐私协议、跨链、链下转移、数据缺失或范围截止|
|标签命中|标签过期、地址复用、共同基础设施或供应商错误|

替代解释不必被“证明为真”，但必须评价是否削弱原假设。

## 9. 金额、路径与图谱复核

### 9.1 金额

- 按`asset_id`分组，不跨资产直接相加；
- UTXO模型区分输入、输出、费用和找零假设；
- 账户模型区分原生资产、代币转移、内部调用和事件日志；
- 铸造、销毁、桥接、重基准等特殊机制需已验证方法；
- 估值是独立派生，保存价格源、时点、币种和方法；
- 任何未知项保持未知，不为守恒美观填0。

### 9.2 路径

路径结果必须带：

- 起点、终点或搜索目标；
- 边类型和方向；
- 时间/高度窗口；
- 最大深度、最大节点/边和截断状态；
- 资产和金额传播规则；
- 过滤、排除、去重和环处理；
- 每条边的原始对象引用。

“未发现路径”只能表述为在冻结范围和参数下未发现。

### 9.3 图表

图表是派生呈现：

- 保留生成数据快照和参数；
- 显示图例、单位、方向、时间和过滤；
- 聚合节点与真实链上地址视觉区分；
- 截断、隐藏小额边和标签来源显式标注；
- 不以节点距离或颜色暗示法律责任。

## 10. 独立复核

### 10.1 复核范围

P0必须全量复核：

- 对象身份和哈希；
- 交易/区块/事件关键字段；
- 金额中间量与守恒；
- 报告使用的路径与关键规则命中；
- 任何主体关联或高风险表述的证据边界。

P1/P2可按批准方案抽样，但发现系统性差异时扩大至全量。

### 10.2 独立性

复核人应：

- 从冻结输入和方法说明开始；
- 使用独立实现、查询或手工计算中的至少一种；
- 不先复制执行人最终结果作为期望值；
- 保存自己的命令、参数、中间量和实际结果；
- 对不能独立复现的供应商输出明确限制。

### 10.3 差异分类

|等级|例子|处理|
|---|---|---|
|D0|格式、措辞不影响含义|记录后可关闭|
|D1|P2显示或非关键字段差异|更正并评估范围|
|D2|P1结果、抽样或限制差异|扩大复核和影响分析|
|D3|P0身份、金额、路径、规则层级差异|阻断报告并启动缺陷|
|D4|授权越界、数据被改写或故意隐瞒|立即停止并升级管理/合规|

## 11. 结论等级与分歧

### 11.1 允许等级

|等级|名称|最低条件|
|---|---|---|
|L1|事实确认|原始对象、方法解析和P0复核一致|
|L2|受限确定性计算|冻结输入、算法、中间量和复算一致|
|L3|规则候选|规则已验证且反例/限制充分|
|L4|统计候选|模型在验证范围内并披露性能与不确定性|
|L5|无法判断|前提、数据、方法或冲突不足以回答|

不得设置“确定主体归属”“确定违法资金”等由技术输出单独达成的等级。

### 11.2 分歧处理

1. 执行人与复核人分别冻结意见和证据。
2. 分析负责人确认分歧是否源自输入、方法、实现或判断。
3. 技术差异通过独立第三计算或新增验证解决。
4. 判断差异由未参与执行的批准角色裁决。
5. 无法解决时报告分歧或`unable_to_determine`。
6. 不得要求任一方删除原始意见以形成一致。

## 12. 执行检查点与停止条件

### CP-1 问题与授权

- [ ] 问题可验证且有明确不回答事项；
- [ ] 输入和分析动作在授权内；
- [ ] 允许结论等级已确定；
- **停止**：无边界问题、越权扩展或要求法律定性。

### CP-2 冻结输入

- [ ] 包、manifest、根哈希和对象校验通过；
- [ ] 链/网络、高度/时间和最终性已固定；
- [ ] 方法、工具、规则和参数已冻结；
- **停止**：输入仍变化、对象断链或版本未知。

### CP-3 执行

- [ ] 原始事实、确定性计算、规则和统计输出分层；
- [ ] 候选、未命中、错误和反向证据均保留；
- [ ] 金额、路径和图过滤可重放；
- **停止**：改阈值不换运行、浮点/跨资产混算或隐藏过滤。

### CP-4 独立复核

- [ ] P0对象、字段、金额和关键路径全量重算；
- [ ] 复核人独立且保存自己的实际结果；
- [ ] 抽样总体和扩大规则明确；
- **停止**：P0差异、同人复核或只看最终报告。

### CP-5 结论

- [ ] 等级与证据层级匹配；
- [ ] 替代解释、负向证据和具体限制进入记录；
- [ ] 分歧已关闭或显式保留；
- **停止**：推断升级为身份/违法确定结论或通用免责声明掩盖缺口。

### CP-6 快照

- [ ] 复核与拟报告引用相同冻结快照；
- [ ] 输出、复核、差异和限制进入证据包；
- [ ] 修改生成新版本并做影响分析；
- **停止**：报告使用未复核的新数据或输出被原位覆盖。

## 13. 最低记录集

- 分析问题与授权引用；
- 冻结数据集manifest和根哈希；
- 方法、工具、环境、规则和参数；
- 运行日志、中间量、候选、未命中和错误；
- 假设卡、替代解释和负向证据；
- 人工排除和决定；
- 金额、路径、图表和过滤记录；
- 复核总体、抽样、独立重算和差异；
- 结论等级、限制、分歧和批准进入报告的决定；
- 冻结结果快照及其对象哈希。
