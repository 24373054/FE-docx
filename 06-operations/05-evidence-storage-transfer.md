# 证据存储、访问、移交与销毁SOP

## 1. 文件目的

本程序规定证据对象和证据包如何入库、分级、封存、访问、复制、导出、移交、定期校验、迁移、法律保全、到期处置及销毁。

当前仓库只保存公开验证材料和脱敏管理记录，不是生产证据库。Git版本控制不能替代WORM、加密、访问审计、可信时间、备份恢复或司法保管链。本程序尚未完成存储选型、配置验证和端到端演练，不得用于真实案件。

## 2. 适用范围与禁止事项

### 2.1 纳入

- 原始、标准化、派生、报告、录像和保管事件对象；
- 公开验证包、内部研发包和未来获准的受控案件包；
- 在线、近线、离线、备份和归档介质；
- 人员/服务访问、复制、导出、脱敏、移交、回执；
- 法律保全、留存、迁移和销毁证明。

### 2.2 禁止

- 将私钥、助记词、生产口令或访问令牌作为普通证据文件保存；
- 将真实案件原始数据、个人信息或受限材料提交到Git；
- 未经批准把对象复制到个人设备、邮件、即时通信或公共网盘；
- 通过修改、覆盖或删除历史事件“修复”保管链；
- 在法律保全、争议、复核或调查未关闭时销毁；
- 仅凭供应商宣传宣称WORM、不可篡改、全删除或加密有效；
- 发送完成即认定接收完成。

## 3. 角色与权限

|角色|职责|禁止|
|---|---|---|
|证据管理员|入库、位置、封存、清单、校验和事件维护|兼任全部批准和复核|
|数据所有者/案件负责人|决定用途、分类、访问和留存要求|直接操作存储绕过流程|
|访问批准人|按最小权限批准目的、对象和期限|批准自身高风险访问|
|第二批准人|高敏导出、解封、迁移和销毁复核|形式审批|
|使用人|只在批准范围访问并管理工作副本|转交、扩散或延长用途|
|安全管理员|密钥、账号、日志、告警和配置|读取无业务需要的内容|
|质量负责人|抽查记录、恢复、哈希、缺陷和CAPA|忽略周期校验失败|
|合规/法律保全负责人|确认保全、期限、通知和释放|口头取消保全|

紧急访问也必须事后由独立角色复核；不得以“紧急”跳过事件记录。

## 4. 数据分类与存储层

### 4.1 分类

|分类|示例|最低约束|
|---|---|---|
|`public`|公开链公开验证包|完整性、版本和公开许可核对|
|`internal`|方法、缺陷、模拟分析|身份访问、加密和审计|
|`sensitive-case`|经授权案件数据、身份关联|强隔离、最小权限、导出双批|
|`restricted`|秘密材料、特殊敏感数据|专用制度；原则上不进入证据包|

### 4.2 存储层

|层|用途|要求|
|---|---|---|
|原始保全区|首次接收的原始对象|不可原位修改、严格访问、完整性基线|
|分析工作区|只读副本和派生输出|与原始区隔离、期限、活动日志|
|交付暂存区|批准的最小披露包|短期、加密、接收后清理|
|备份区|可恢复副本|隔离、加密、恢复演练|
|归档区|长期留存|格式可读性、定期校验、迁移计划|

存储等级由数据分类、案件状态、访问频率、恢复目标和法律/合同要求决定，不按文件扩展名判断。

## 5. 详细控制要求

|控制ID|控制主题|强制要求|停止/拒绝条件|
|---|---|---|---|
|SOP-005-C001|入库清单|接收时记录包/对象ID、来源、数量、字节数、哈希、分类、移交人、接收人、时间和异常|清单缺失或与实际不符|
|SOP-005-C002|存储等级|按分类、状态、访问、恢复和留存决定原始、工作、交付、备份和归档位置|位置未批准或跨区域不明|
|SOP-005-C003|WORM|只有配置、保留锁、管理员边界、改写/删除负向测试和恢复均验证后才可称WORM|仅供应商宣称或管理员可静默改写|
|SOP-005-C004|加密|记录静态/传输算法、密钥ID、权限、轮换、恢复和失败；密钥与数据分离|密钥同位置、无法恢复或算法未批准|
|SOP-005-C005|访问申请|申请包含人员/服务、目的、对象、动作、期限、位置和输出；默认拒绝|范围含糊、目的不符或无到期|
|SOP-005-C006|双人审批|高敏访问、解封、批量复制、外部导出、迁移、保全释放和销毁由独立角色双批|同一人自批或事后追认|
|SOP-005-C007|复制记录|登记源/目标、前后哈希、工具、目的、批准、时间、位置和副本期限|哈希不符或目标不受控|
|SOP-005-C008|导出审批|导出前核对接收方、最小披露、对象允许清单、渠道、加密、期限和回收|完整包直接外发或接收方未知|
|SOP-005-C009|脱敏副本|脱敏作为派生对象保存规则、前后对象、不可逆风险、复核和重新识别限制|覆盖原件或无法证明删减范围|
|SOP-005-C010|介质标识|使用无敏感信息的唯一介质ID、分类、包清单哈希、状态和位置；标签与系统登记一致|标签暴露案情/身份或介质无法对应|
|SOP-005-C011|封存|记录对象集合、容器/根哈希、封存主体、时间、位置、封签/锁和状态|封存后可无事件修改|
|SOP-005-C012|解封|有理由、范围、双批、解封前校验、执行/见证和工作副本；结束后重新封存|哈希失败、无批准或直接改原件|
|SOP-005-C013|移交清单|记录双方、对象/包、版本、数量、容器哈希、介质/渠道、时间、异常和风险|清单与交付物不一致|
|SOP-005-C014|接收回执|接收方独立计算哈希并记录实际数量、时间、解密/打开、异常和决定|无回执或不一致仍视为完成|
|SOP-005-C015|定期哈希验证|按风险覆盖介质、年龄、分类和历史缺陷；保存总体、抽样/全量、工具和实际差异|只保存“通过”摘要或差异未隔离|
|SOP-005-C016|介质迁移|迁移前批准、源/目标清单、工具、格式、前后哈希、恢复测试和旧介质处置|仅复制未验证或旧介质提前销毁|
|SOP-005-C017|法律保留|记录触发、范围、保全人、开始、审查、通知、系统实施和书面释放|任何活跃保全对象被修改/销毁|
|SOP-005-C018|留存期限|按法律、委托、合同、投诉/争议、验证和内部政策逐对象确定起算与到期|一刀切期限或依据不明|
|SOP-005-C019|销毁批准|到期、保全、调查、备份、副本和接收方义务全部核对后双批|保全有效、范围不全或权限不足|
|SOP-005-C020|销毁证明|记录对象/介质、方法、工具、执行/见证、时间、验证、失败和残留范围|无法验证却宣称全部销毁|

控制仍为`not_implemented`；未来供应商合同或配置截图不能单独升级状态。

## 6. 入库流程

### 6.1 接收前

- 创建接收事件和受控暂存位置；
- 核对移交人、授权、分类和预期清单；
- 准备隔离扫描和只读验证环境；
- 确认存储容量、加密、访问组和备份策略；
- 对未知介质/文件制定恶意内容隔离措施；
- 真实案件不得先经过Git或个人同步盘。

### 6.2 接收与验证

1. 记录介质/容器外观、封签和实际接收时间。
2. 读取移交清单但不自动信任其值。
3. 独立统计对象数、字节数并计算容器/对象哈希。
4. 比较发送值；差异生成`discrepancy_recorded`。
5. 执行恶意内容扫描时不得改写原始字节；扫描记录单独保存。
6. 建立原始保全对象和只读状态。
7. 生成接收回执；差异未解决时选择拒绝或隔离接收。

### 6.3 入库

- 分配逻辑位置与对象存储版本；
- 应用分类、访问组、加密和保留策略；
- 保存首次存储完整性基线；
- 创建工作副本需另走复制事件；
- 将清单、回执、位置和状态写入证据包/保管事件；
- 第二人员抽查高敏对象和策略实际生效。

## 7. 访问、复制和工作副本

### 7.1 访问申请

申请必须回答：

- 谁或哪个受控服务；
- 为什么以及依据哪个任务；
- 哪些对象/字段；
- 读、复制、导出、解封或管理何种动作；
- 从哪里、到哪里；
- 开始/结束和自动到期；
- 是否生成新对象；
- 数据最小化和销毁/回收计划。

### 7.2 授权决策

批准人核对职责、培训、人员授权、任务状态、分类、利益冲突和替代方案。对敏感原始对象、批量导出、外部接收、解封和销毁使用双人审批。

### 7.3 工作副本

1. 从已校验源创建副本。
2. 记录复制工具和前后哈希。
3. 目标放入批准分析区并设置期限。
4. 分析只修改派生目录，不覆盖工作副本。
5. 任务结束核对需回存对象和临时文件。
6. 清理工作区并生成销毁/回收记录。

访问日志故障时默认停止高敏操作，除非经紧急批准并使用可核验替代记录。

## 8. WORM、加密与备份

### 8.1 WORM验证门

在使用“WORM”“不可变存储”表述前必须测试：

- 普通用户不能改写/删除锁定对象；
- 管理员、根账号和供应商支持通道的实际能力；
- 保留期缩短、时钟变化和策略绕过；
- 版本、软删除、生命周期规则和复制行为；
- 账户/密钥丢失后的恢复；
- 日志能否发现失败和成功的管理动作。

未完成时记录为“候选对象锁控制”，不得宣传不可篡改。

### 8.2 加密

- 数据密钥不与密文同目录；
- 密钥ID不保存秘密本身；
- 权限、轮换、撤销、备份和恢复有记录；
- 加密容器同时保留明文包根哈希和密文容器哈希；
- 定期用独立恢复环境验证解密；
- 离职、泄露、算法弃用触发影响分析和重加密计划。

### 8.3 备份与恢复

备份成功日志不等于可恢复。恢复演练必须：

- 从指定恢复点在隔离环境恢复；
- 计算对象和包完整性；
- 验证格式、读取器、权限和密钥；
- 记录恢复时间目标/恢复点目标的实际值；
- 说明未覆盖对象和失败；
- 不覆盖生产/原始保全区。

## 9. 导出、脱敏和移交

### 9.1 导出

- 基于批准允许清单从内部完整包生成交付包；
- 去除无关身份、日志、秘密和内部备注；
- 报告引用必须在交付包内可解析；
- 脱敏生成派生对象并记录规则；
- 机器验证和独立复核后封装；
- 暂存区设置自动到期并纳入清理检查。

### 9.2 移交

发送前双方约定：

- 接收主体和联系人验证方式；
- 包/报告ID与版本；
- 容器格式、加密和密钥通道；
- 哈希算法和发送值；
- 接收时限、异常处理和回执字段；
- 接收后的留存、再披露和销毁义务。

### 9.3 接收失败

|失败|处理|
|---|---|
|无法解密|保留密文与事件，核对密钥ID和通道|
|哈希不符|拒绝使用，隔离实际文件并调查|
|对象/附件缺失|与允许清单核对，重新组装新版本|
|错误接收方|立即停止链接/访问、启动泄露响应和通知评估|
|回执超时|状态保持未交付并升级，不假定已收|
|重复发送|分别登记发送事件和接收决定|

## 10. 定期校验、迁移与归档

### 10.1 校验计划

计划按以下因素分层：

- 数据分类和案件风险；
- 介质/对象年龄和供应商变化；
- 访问/迁移频率；
- 先前哈希差异、硬件告警和缺陷；
- 格式、算法和读取器淘汰风险；
- 法律保全和出庭/复核时点。

P0对象、迁移前后对象和待交付对象优先全量校验。

### 10.2 差异

哈希不一致时：

1. 停止访问、复制、迁移和销毁；
2. 隔离受影响位置并保存实际对象；
3. 比较副本、备份、版本和事件；
4. 确定影响对象、案件、报告和接收方；
5. 恢复只从已验证来源进行并保留坏对象；
6. 启动缺陷、CAPA和必要通知。

### 10.3 迁移

迁移不是简单复制。需冻结源清单、目标配置、工具和接受准则，执行前后哈希、对象数、字节数、权限、加密、恢复和读取测试。旧介质在目标完成独立验证且无保全要求后才进入销毁审批。

## 11. 法律保全、留存与销毁

### 11.1 法律保全

保全触发可能来自诉讼/调查、投诉、审计、合同争议、主管机关要求或内部重大缺陷。合规/法律角色书面确定：

- 涉及案件、主体、对象、日期和数据类型；
- 系统、备份、工作副本和接收方范围；
- 暂停哪些自动生命周期/销毁；
- 通知对象和确认；
- 定期审查和书面释放。

技术团队不得自行判断保全已结束。

### 11.2 留存决定

每一类对象记录依据、起算点、期限、保全覆盖、责任人和到期动作。方法验证原始记录、案件证据、临时工作副本和交付暂存不得套用同一期限。

### 11.3 销毁

销毁前清单覆盖主存储、版本、回收站、缓存、临时副本、备份、导出和介质。销毁方法与介质/加密设计匹配。云服务无法证明物理销毁时，应如实记录合同能力、加密密钥处置和残余限制，不得宣称绝对删除。

## 12. 执行检查点与停止条件

### CP-1 入库

- [ ] 授权、分类、清单和接收位置已准备；
- [ ] 接收方独立核对数量、字节数和哈希；
- [ ] 原始对象与工作区分离；
- **停止**：清单不一致、来源不明、哈希失败或未批准位置。

### CP-2 访问

- [ ] 主体、目的、对象、动作、位置和期限明确；
- [ ] 高敏动作按规则双批；
- [ ] 人员和服务访问都记录；
- **停止**：共享账号、无到期、日志故障或目的漂移。

### CP-3 复制/导出

- [ ] 源目标哈希一致；
- [ ] 脱敏与最小披露有允许清单和复核；
- [ ] 临时副本有清理计划；
- **停止**：目标不受控、完整包无差别外发或脱敏覆盖原件。

### CP-4 封存/解封

- [ ] 封存集合和根/容器哈希固定；
- [ ] 解封有理由、双批、前校验和工作副本；
- [ ] 结束后重新封存；
- **停止**：无批准、哈希不符或直接修改原始保全对象。

### CP-5 移交

- [ ] 接收方、渠道、加密、密钥通道和回执字段已约定；
- [ ] 发送与接收为独立事件；
- [ ] 哈希不符时拒绝；
- **停止**：错误接收方、无回执、无法解密或对象缺失。

### CP-6 归档/迁移

- [ ] 完整性、格式、读取器、密钥和恢复均测试；
- [ ] 迁移前后清单一致；
- [ ] 旧介质未提前销毁；
- **停止**：无法恢复、格式失读、差异未调查。

### CP-7 销毁

- [ ] 到期依据、保全、争议、备份和副本已核对；
- [ ] 双人批准、方法和范围明确；
- [ ] 实际执行与验证形成证明；
- **停止**：任何有效保全、范围不全、验证失败或只有口头批准。

## 13. 最低记录集

- 入库/移交清单和接收回执；
- 分类、位置、存储等级、访问组和加密/密钥ID；
- WORM配置与负向测试（如声称）；
- 访问申请、批准、实际访问和异常；
- 复制、导出、脱敏、封存和解封事件；
- 定期校验总体、样本、结果和差异；
- 备份恢复、归档和迁移记录；

- 销毁申请、批准、执行、见证、验证和证明；
- 失败、调查、CAPA和通知。
