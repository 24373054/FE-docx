# 可测试需求目录

## REQ-GOV-001 — 治理文控准确性

- 优先级：P0。
- 需求：系统和流程必须使治理文控满足准确性。
- 输入必须有来源、授权、时间、版本、完整性和责任人。
- 处理只能使用批准方法、工具、规则、参数和环境。
- 输出必须绑定证据索引、结论类型、限制和复核状态。
- 正常验收：已知答案与真值一致。
- 边界验收：缺字段、极值、重组或候选不唯一时受控阻断。
- 负向验收：未授权、哈希失败、工具失效或复核缺失不得签发。
- 审计验收：可重建人员、时间、输入、动作、参数、输出和批准。
- 性能验收：超时只能排队/扩容，不得跳过验证。
- 控制：CTL-GOV-01。
- 测试：TST-GOV-01-01。
