# 人员独立性与利益冲突管理

## 1. 文件目的

识别、评价和处置可能影响公正性、客观性、保密性或复核独立性的财务、关系、角色、商业、学术和信息冲突。

披露本身不必然禁止参与；隐瞒、无法控制或涉及自我复核的高风险冲突必须回避或阻断。

当前没有公司具名人员，故不存在已完成的年度、项目或任务声明。GOV-010签批后方可运行。

## 2. 适用对象

- 董事、管理层、员工、实习人员和外聘人员；
- 律师、独立专家、讲师、导师和评估人；
- 供应商、合作鉴定机构和关联公司接口人员；
- 参与受理、采集、分析、真值、方法、工具、复核、报告、批准、采购和付款的人员；
- 可以访问研究、访谈、验证或未来案件数据的人员。

## 3. 声明层级

|声明|时间|范围|
|---|---|---|
|年度声明|加入项目及每年|持仓、关系、任职、顾问、供应商、公开立场|
|项目声明|进入FE-docx或重大子项目|项目利益、竞争、合作、知识产权、预算|
|任务声明|每次P0任务分派前|是否建立、开发、执行、销售或持有相关利益|
|变化声明|关系发生后2个工作日内|新增持仓、亲属、雇佣、礼品、公开立场等|
|发布确认|报告/真值/方法/工具批准前|确认没有未披露变化|

不允许用年度声明代替任务级独立性核验。

## 4. 处置等级

|等级|情形|处置|
|---|---|---|
|R0|无相关冲突|正常分派，保留声明|
|R1|可披露且不影响决定|记录、加强复核|
|R2|可通过信息隔离/限制控制|隔离、限定角色、独立复核|
|R3|显著影响或自我复核|回避、更换人员或外部复核|
|R4|隐瞒、成功收费、重大财务利益或无法控制|禁止参与、事件/CAPA、历史影响评估|

质量负责人提出处置；被评估人不得单独批准自身R1至R4。

## 5. 详细控制要求

### ORG-005-C001｜年度声明

- 覆盖虚拟资产持仓/经济利益、亲属、雇佣、顾问、供应商、客户、学术和公开立场。
- 记录拒绝披露或无法核验的事项；不得默认“无冲突”。
- 年度到期自动使新任务分派blocked。

### ORG-005-C002｜案件/项目级声明

- 分派前列出主体、对象、合作方、供应商、争议类型和已知关联。
- G0公开研究也需项目声明，尤其是数据源和工具供应关系。
- 未来真实案件使用更严格案件级声明和必要披露。

### ORG-005-C003｜财务利益

- 披露可能受项目结论影响的虚拟资产、股权、债权、奖励、投资和衍生利益。
- 对具体资产/协议有实质利益者不得单独分析、复核或批准相关结论。
- 不要求在公开仓库披露具体金额；由受控记录评估重要性。

### ORG-005-C004｜亲属关系

- 披露近亲属与客户、对手方、合作机构、供应商或监管接口的关系。
- 质量负责人按影响、角色和信息接触决定R1至R4。
- 不得因隐私原因完全省略冲突判断；可最小化记录。

### ORG-005-C005｜既往雇佣

- 披露与相关主体、工具商、交易平台、律所、机构或监管咨询有关的既往任职。
- 掌握内部信息、参与争议对象或离职义务未清时提高处置等级。
- 时间经过本身不自动消除冲突。

### ORG-005-C006｜顾问关系

- 披露现有和近期顾问、兼职、讲师、推荐费、社区管理和技术支持关系。
- 外部专家合同必须声明其他客户和潜在利益。
- 顾问不得复核自己向项目提供的同一方案。

### ORG-005-C007｜供应商关系

- 披露礼品、试用、返佣、认证、合作内容、就业洽谈和持股。
- 供应商培训/认证人员不得单独批准供应商工具准确性。
- 采购选择、技术验证、验收和付款分离。

### ORG-005-C008｜销售激励

- 技术、质量和复核岗位绩效不得以结论有利、案件成功、追回金额或报告数量为核心。
- 商业人员不得改变技术事实、限制或停止结论。
- 发现干预时保留原始记录并升级质量负责人。

### ORG-005-C009｜成功收费

- 项目默认禁止以解冻、追回、定罪、胜诉、资产处置价格或鉴定结论为条件的成功收费。
- 任何例外必须先取得中国律师意见和管理层书面决定；仍不得影响技术结论。
- 未批准例外为R4。

### ORG-005-C010｜媒体立场

- 披露对相关主体、资产、协议或争议已发表的强烈公开立场。
- 一般学术观点不自动回避，但需评价是否预断具体结论。
- 项目人员不得借项目身份发布未经批准的个案/监管观点。

### ORG-005-C011｜学术合作

- 披露论文、开源、资助、联合研究和数据共享关系。
- 学术贡献与商业/案件评价分别记录。
- 合作研究者不能单独复核自己建立的样本、标签或方法。

### ORG-005-C012｜自我复核

- 建立真值者不得作同一真值最终独立复核/批准。
- 方法/工具开发者可提供解释，但不能成为唯一验证者。
- 报告编制者不能成为唯一技术、质量和发布批准人。
- 不同实现路径不能替代不同自然人。

### ORG-005-C013｜替代人员

- ORG-006为P0岗位维护替补或外部专家路径。
- 替代人员必须完成同等身份、能力、保密、冲突和任务授权。
- 无合格替代时任务保持blocked，不降级独立性门。

### ORG-005-C014｜信息隔离

- 对可控制的R2冲突设置独立账户、数据域、会议、文件权限和沟通记录。
- 隔离方案写明允许/禁止信息、期限、监督和违规响应。
- 不能验证隔离有效时提升为R3回避。

### ORG-005-C015｜公正性风险评估

- 质量负责人至少每季度汇总冲突类型、角色兼任、商业压力、供应商和例外。
- 管理层评审资源是否足以保持独立性。
- 评估结论包括接受、加强控制、暂停活动、补充人员或停止路线。

### ORG-005-C016｜违规处置

- 未声明、虚假声明、绕过回避、接触隔离信息或商业干预按不符合处理。
- 立即隔离人员/结果，检索未完成及历史对象影响。
- 根据严重性暂停/撤销授权、重做、通知和CAPA。
- 恢复需要原因关闭、重新声明、再培训/考核和具名批准。

## 6. 任务级独立性检查

分派P0任务前回答：

- [ ] 复核人没有建立该真值、方法、工具或主要输出；
- [ ] 复核人不会看到预期答案后照抄；
- [ ] 复核环境和输入可以独立取得并记录；
- [ ] 复核人与被复核人不存在汇报/绩效导致的实质压力，或已有加强控制；
- [ ] 不存在相关财务、亲属、雇佣、顾问、供应商或成功收费关系；
- [ ] 结论方向不会直接决定个人报酬；
- [ ] 信息隔离和最小权限可验证；
- [ ] 发生差异时复核人有权阻断。

任一项为“否”且没有批准处置时，任务状态为blocked。

## 7. 决策与升级

1. 被评估人提交事实，不自行定级。
2. 质量负责人核验必要事实并初评R0至R4。
3. R0由质量负责人记录；R1/R2由质量负责人和项目负责人双签。
4. R3由项目发起人确认回避/替代。
5. R4进入不符合/CAPA并由管理层决定历史影响和纪律/合同措施。
6. 质量负责人本人存在冲突时，由项目发起人指定独立成员处理。
7. 决定可被新事实、投诉、审计或外部意见重新打开。

## 8. 主要风险与控制

|风险|控制|停止/恢复|
|---|---|---|
|声明形式化|核验、任务级更新和审计抽样|缺证据不分派|
|小团队一人闭环|替补/外部专家|不能分离则blocked|
|持币/股权影响|财务利益评估和回避|换人、重做|
|供应商影响工具结论|采购/验证/批准分离|独立验证|
|商业人员施压|质量否决和干预记录|暂停发布|
|信息隔离失效|账户、日志和监督|事件/CAPA后恢复|
|隐瞒关系|R4和历史影响检索|重新评价全部相关结果|

## 9. 记录与留存

|记录|密级|最低内容|
|---|---|---|
|年度声明|公司机密|关系类别、确认、日期、签名|
|项目/任务声明|公司机密/案件敏感|主体、对象、角色、事实|
|风险评价|公司机密|R级、依据、控制、决定人|
|信息隔离|敏感|账户、数据、沟通、期限、日志|
|回避/替代|公司机密|原人员、替代、交接、授权|
|违规与历史影响|按最高数据密级|范围、对象、处置、CAPA|

敏感持仓、亲属和个人关系不进入公开仓库；只在公开审计中报告“已完成/未完成”和处置状态。

## 10. 验收准则

- [ ] 年度、项目、任务、变化和发布确认分层；
- [ ] 16类冲突均有事实、评价和处置路径；
- [ ] 被评估人不能单独批准自身冲突；
- [ ] 自我复核和不同实现替代人员独立性被明确禁止；
- [ ] R0至R4决定与证据匹配；
- [ ] 替代人员受相同能力、授权和保密控制；
- [ ] 信息隔离有账户、日志、期限和失效处理；
- [ ] 违规会触发人员/结果隔离和历史影响评估；
- [ ] 当前没有虚构已完成声明；
- [ ] 对应16项需求已复核；
- [ ] 16项控制仍为not_implemented，16项测试仍为not_executed。

## 11. 当前结论

冲突分类、任务独立性和处置流程已形成草案，但尚无自然人声明、评价或决定。当前Bitcoin GT2、模板和所有方法/工具批准继续因人员独立性缺失而blocked。

## 12. 授权与替补矩阵

|决定|主责|必须回避/独立要求|替补或升级|当前状态|
|---|---|---|---|---|
|年度/任务事实申报|每名相关人员|申报人不得自行决定风险等级|质量负责人核验|未运行|
|R0记录|质量负责人|本人有关系时回避|独立质量替补|未运行|
|R1/R2附条件参与|质量负责人+项目负责人|不得由被评估人参与唯一决定|项目发起人指定无冲突替补|未运行|
|R3回避/替代|项目发起人|有直接利益时回避|同等公司权限人员或公正性小组|未运行|
|R4违规与历史影响|管理层|涉事管理者不得参与唯一决定|外部独立专家、法律与质量联合评估|未运行|
|替代人员接受|质量负责人|核验能力、授权、保密和新冲突|无合格替补则任务blocked|未运行|

替补人员不得继承原人员的冲突结论或访问权限；必须重新声明、评价和授权。
