# 环境与部署隔离架构

## 1. 文件目的

定义开发、测试、验证、预生产、未来生产、任务分析、节点、证据、管理、日志、备份和离线验证区域的隔离与数据禁止复制规则。

本项目没有产品代码或生产系统；所有环境均为目标架构，当前只有本地公开研究工作区。

## 2. 当前状态与原则

- 生产、预生产、受控验证和案件分析环境数量为0；
- 验证证据包位于公开无敏感信息工作区；
- 不允许用真实案件/个人数据测试；
- 环境分离以身份、网络、数据、配置、秘密和日志共同实现；
- 从低控制环境向高控制环境迁移制品必须重新验证。

## 3. 环境层级

|环境|允许数据|允许活动|禁止|
|---|---|---|---|
|开发|合成/公开最小集|文档、候选脚本|真实敏感数据|
|单元测试|合成固定样例|逻辑/契约测试|外部网络依赖|
|验证|批准公开/脱敏样本|方法/工具验证|生产任务|
|预生产|合成或批准仿真|部署/恢复演练|真实输出发布|
|生产（未来）|获批任务副本|批准服务|实验性变更|
|离线验证|冻结包|独立复算|隐式网络/生产状态|

## 4. 部署不变量

- 环境身份、账户、网络、配置、秘密、数据和日志隔离；
- 制品由低环境产生但经受控发布进入高环境；
- 生产数据不反向复制到开发/测试；
- 管理、日志、备份与业务区分离；
- 所有跨环境动作有变更、清单、哈希和回执。

## 5. 详细控制要求

### ARC-003-C001｜开发环境

- 仅使用公开/合成数据和非生产秘密，允许快速实验但输出标记候选。
- 本地开发设备不得被称为受控实验室。

### ARC-003-C002｜单元测试环境

- 使用固定、可重复、无网络的最小样例验证组件逻辑。
- 单元测试通过不能替代方法、集成、验证或人员能力。

### ARC-003-C003｜验证环境

- 绑定批准样本、真值、工具制品、依赖、参数、人员和记录。
- 与开发隔离，运行后保存失败与环境快照。

### ARC-003-C004｜预生产环境

- 未来预生产复制生产拓扑/配置而不复制真实数据，验证发布、监控、恢复和回滚。
- 当前不存在，不得以本地模拟冒充。

### ARC-003-C005｜生产应用区

- 仅运行批准制品/方法/配置，处理获批任务并最小外联。
- G1至G3门未通过前保持未部署。

### ARC-003-C006｜案件分析区

- 按任务/密级隔离工作空间、对象、人员、工具、导入和导出。
- 分析人员不能访问其他任务或修改原始证据区。

### ARC-003-C007｜节点网络区

- 节点与互联网/同伴交互，与证据/应用区通过受控只读接口连接。
- RPC管理/钱包/敏感接口不向分析区开放。

### ARC-003-C008｜证据存储区

- 原始对象、派生、交付和保管事件分层保存，写入受控、读取审计。
- 业务应用不能物理删除或覆盖原始对象。

### ARC-003-C009｜管理区

- 跳板、身份、配置、密钥和管理工具位于独立区，强认证/审批。
- 管理区不用于日常分析或浏览互联网。

### ARC-003-C010｜日志审计区

- 从各区单向/受控接收日志，独立保留、查询和完整性保护。
- 业务管理员不能删除本人活动日志。

### ARC-003-C011｜备份区

- 备份与源环境隔离，包含不可变/离线/异地策略和恢复身份。
- 备份账户与生产管理员分离。

### ARC-003-C012｜离线验证区

- 通过受控介质/单向流程导入冻结包，禁止隐式网络与生产凭据。
- 导出只有验证记录/批准结果，保持原对象哈希。

### ARC-003-C013｜跳板机

- 管理访问经受控跳板，记录身份、目标、命令/会话、时间和批准。
- 跳板机不得成为证据临时存储或共享账号入口。

### ARC-003-C014｜网络白名单

- 规则按源、目的、协议、端口、身份、用途、期限和负责人配置。
- 通用出站互联网、0.0.0.0/0和永久例外需禁止或高风险批准。

### ARC-003-C015｜容器镜像

- 镜像来源、Dockerfile/构建说明、基础镜像、依赖、SBOM和哈希冻结。
- 未扫描、latest或不可重建镜像不得进入高环境。

### ARC-003-C016｜主机加固

- 最小服务、补丁、账号、磁盘加密、日志、时间、恶意防护和基线核查。
- 偏离有原因、风险、期限和补偿控制。

### ARC-003-C017｜时间同步

- 每区主机/服务记录统一时源、时区、偏差、告警和离线处理。
- 时间异常影响顺序/签名/日志时停止相关运行。

### ARC-003-C018｜密钥服务

- 环境秘密分离、不可复制、最小使用、轮换、备份和审计。
- 不在镜像、配置库、日志或模板中存储明文秘密。

### ARC-003-C019｜环境配置隔离

- 配置按环境独立命名、权限、版本和默认值，禁止自动继承未审差异。
- 发布包显式比较配置差异。

### ARC-003-C020｜数据禁止复制规则

- 真实/敏感数据禁止复制到开发、测试、个人设备、公共云盘或公开仓库。
- 必要脱敏副本需新对象ID、规则、批准、验证、保留和删除。

## 6. 部署与数据流

制品：开发/构建 → 审查/签名 → 验证 → 预生产 → 生产。

数据：外部隔离 → 证据区 → 任务只读/派生 → 复核/报告 → 交付；不逆向流入低环境。

## 7. 环境晋级门

每次晋级验证制品、依赖、配置、秘密引用、数据、权限、网络、日志、备份、回滚和批准。环境名称或部署成功不等于晋级批准。

## 8. 主要风险与控制

|风险|控制|停止|
|---|---|---|
|真实数据进测试|禁止复制/脱敏|发现敏感对象|
|环境秘密复用|独立密钥|跨区相同凭据|
|节点直连证据|网络分段|未审接口|
|管理员删日志|独立审计区|日志缺口|
|latest镜像|制品锁定|不可重建|
|本地模拟冒充生产|状态证据|无部署/批准|

## 9. 记录

环境清单、网络图、数据流、资产、配置、秘密、加固、镜像、访问、部署、差异、测试和恢复记录按最高密级保存。

## 10. 验收准则

- [ ] 环境、区域、数据和网络边界完整；
- [ ] 生产数据不可流向低环境；
- [ ] 管理、日志、备份和离线验证独立；
- [ ] 制品/配置/秘密/时间受控；
- [ ] 发布、回滚和恢复可验证；
- [ ] 当前部署数量保持0。

## 11. 当前结论

目标部署隔离已定义，但未实施。任何图或表均不得作为系统/实验室已建成证据。

## 12. 架构决策与接口约束

- [ ] 环境清单和信任区批准；
- [ ] 网络/数据流和禁止复制经安全/合规评审；
- [ ] 制品、配置、秘密和访问路径验证；
- [ ] 日志、备份、离线验证和回滚演练；
- [ ] 真实数据扫描/阻断机制通过。

跨环境接口只接受经签名/哈希的批准制品或带对象ID、密级、授权和清单的数据包；禁止共享数据库、共享秘密和未审文件系统复制。
