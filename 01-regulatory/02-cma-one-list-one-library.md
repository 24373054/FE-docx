# CMA一单一库能力决策与申报准备

## 1. 文件目的

把2026年6月1日起实施的CMA“一单一库”制度转化为查询、映射、申请、报告和标志控制。

本程序不决定司法鉴定许可，也不证明区块链专项项目已经入库。

## 2. 适用范围

适用于：

- 拟申请CMA的检验检测项目；
- 库内与库外项目判断；
- 标准、对象、项目和参数表述；
- CMA报告模板、标志和宣传；
- 能力库变更影响。

不适用于代替司法行政、CNAS或法院决定。

## 3. 已核验规则

市场监管总局2026年第14号公告规定：

- 资质认定按事项清单和能力项目库办理；
- 审批发证以作出审批决定时的库为准；
- 库外项目原则上可按能力具备、风险可控、用户自愿提供服务；
- 库外报告不得标注CMA；
- 同一报告混合库内方法与库外方法时原则上不得标注CMA；
- 能力项目库动态调整并允许按程序提出建议；
- 其他法律法规另有资质要求的，从其规定。

公告和问答不能替代具体项目映射答复。

## 4. 当前项目快照

2026年7月29日已有受控查询记录：

|关键词|总结果|司法鉴定检测|解释|
|---|---:|---:|---|

## 6. 标准工作流程

### 6.1 定义能力

建立一行能力描述：

`对象 + 项目/参数 + 依据方法 + 输出 + 限制`

“区块链追踪”不是合格的单独申报描述。

### 6.2 查询

1. 保存事项清单版本；
2. 在能力库按标准号、正式名称和候选关键词查询；
3. 保存完整条件、结果、失败和时间；
4. 检查标准现行性与库备注；
5. 由第二人复核。

### 6.3 分类

- 库内且范围匹配：进入申请差距评估；
- 库内但范围不匹配：停止并咨询；
- 库外：评估其他法律资质和普通服务边界；
- 结果不明：保持研究，不签约、不宣传。

### 6.4 申请

- 冻结人员、设备、环境、方法和范围；
- 形成申请证据包；
- 跟踪库调整；
- 记录受理、评审、不符合和决定；
- 不预设批准结果。

### 6.5 报告与宣传

报告发布前逐项核验：

- 项目是否在证书附表；
- 方法、对象和参数是否一致；
- 是否混入库外结果；
- 标志位置与声明是否合规；
- 证书是否有效；
- 客户是否要求误导性措辞。

## 7. 区块链项目映射原则

|候选活动|当前状态|下一证据|
|---|---|---|
|公开链原始对象提取|未确认专项映射|向市场监管部门书面咨询|
|交易字段确定性复算|库外研发候选|标准/方法/项目映射|
|多源一致性检查|库外研发候选|检验对象和方法定义|
|地址聚类/标签|高推断风险|方法确认与输出降级|
|资产定价/兑换|不纳入本项目|金融监管阻断|

不得因“电子数据”关键词命中而自动宣称全部区块链能力可获CMA。

## 8. 主要风险与控制

|风险|预防|发现|处置|
|---|---|---|---|
|只按关键词判断|标准号与项目表述并查|独立复核|咨询并保持未确认|
|库外误盖CMA|模板分区|发布前扫描|撤回、通知、CAPA|
|混合报告误标|结果逐项标记|报告抽查|拆分或移除标志|
|动态库变化|月度/事件查新|到期提醒|重新映射|
|证书过期仍宣传|证书状态联锁|网站巡查|立即下线|
|沙盒被误写获批|限定研究状态|管理评审|纠正宣传|

## 9. 查询证据最低字段

- 平台和入口；
- 查询人、日期、时区；
- 关键词、标准号和筛选；
- 返回总数和逐项结果；
- 页面/导出文件；
- 字节数和SHA-256；
- 失败、验证码、分页和权限限制；
- 复核人和结论；
- 下次查询日期。

## 10. 验收准则

- [ ] 项目描述拆成对象、参数、方法和输出；
- [ ] 事项清单及能力库查询可复现；
- [ ] 标准状态和备注已核验；
- [ ] 库外服务完成其他法律资质审查；
- [ ] 三类报告模板已区分；
- [ ] 标志和宣传只引用有效证书范围；
- [ ] 动态调整有责任人和触发器；
- [ ] 未把查询未命中写成主管机关否定。
