# 官方与技术来源入口登记册

## 1. 用途

本登记册定义外部来源的选择、身份、快照、复核和引用入口。

具体监管命题、证据等级、查询条件和负面事实见[`REF-008`](./08-authority-evidence-register.md)；市场、机构和采购证据见[`REF-009`](./09-market-and-competition-evidence-register.md)。

登记来源不表示其自动适用于本公司、具体服务、申请事项或案件。

## 2. 来源优先级

|等级|来源|允许用途|
|---|---|---|
|S1|法律法规、司法解释、部门规章、主管机关正式文件|确认外部规则候选|
|S2|主管机关办事指南、公告、名录、书面答复|确认程序、状态和具体范围|
|S3|标准发布组织的现行标准/认可规范|能力与技术要求|
|S4|协议规范、官方客户端、EIP/接口规范和版本发布|链级技术规则|
|S5|官方案例、政府采购和机构公开材料|需求/实践线索|
|S6|论文、社区、媒体、供应商和搜索摘要|发现线索，不单独支持强结论|

相互复制的多个页面不是多个独立来源。

## 4. 来源记录最低字段

- source ID；
- 正式标题、发布主体和文件类型；
- 文号/标准号/版本；
- 发布、生效、废止和访问日期；
- 官方URL、下载文件名或查询入口；
- 原始文件/页面快照ID、字节数和SHA-256；
- 适用主体、地域、事项、时间和条款；
- 证据等级与是否独立；
- 对需求、方法、工具、人员、场所、合同和宣传的影响；
- 责任人、下次复核日、冲突和关闭证据。

搜索结果页和摘要只记录为定位过程，不作为正式来源对象。

## 5. 动态查询

CMA一单一库、司法鉴定名册、机构业务范围、CNAS认可状态等属于动态事实。

每次正式使用须保存：

1. 查询入口和完整条件；
2. 查询日期、时区和执行人；
3. 返回页/导出对象；
4. 结果数量及目标记录；
5. 页面或文件哈希；
6. 查询失败、验证码、登录或分页限制；
7. “截至查询日”的限定措辞。

旧查询不能证明当前状态。

## 6. 技术来源

技术方法须优先使用：

- 目标网络采用的协议规范；
- 目标高度适用的分叉规则；
- 官方/参考客户端精确版本；
- 可复算原始对象和测试向量；
- 接口规范及实现差异记录；
- 版本发布、弃用和安全公告。

EIP、TRC标准或代码存在不等于目标链/合约已采用。

## 7. 冲突与失效

出现以下情况时登记差距并暂停强结论：

- 官方页面失效或内容无版本；
- 不同主管机关文件范围冲突；
- 动态名录与证书/附件不一致；
- 协议规范与客户端实现不同；
- 中文转述与正式原文不同；
- 供应商/媒体结论无法回到原始来源。

冲突不得通过多数投票或选择有利来源解决。

## 8. 使用检查

- [ ] 来源主体和官方入口已核验；
- [ ] 版本、发布日期、生效状态和适用范围明确；
- [ ] 原始对象或合法快照已保存；
- [ ] 动态查询条件和日期完整；
- [ ] 关键命题能定位到具体条款/字段；
- [ ] 冲突、负面事实和未知项已登记；
- [ ] 正式申报/签约/发布前已重新核验；
- [ ] 引用没有超过来源支持范围。
