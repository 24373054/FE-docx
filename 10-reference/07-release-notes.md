# 发布与基线处置记录

## v0.3.0 — 2026-07-30 — 验证准备与负面证据基线

### 已完成

- 建立T1至T3首批方法验证总计划和V0至V5证据门；
- 将方法确认、工具验证、样本与真值管理三份历史生成稿重构为受控草案；
- 逐条复核对应60项需求并替换60条通用测试预期；测试状态仍为`not_executed`；
- 建立Bitcoin、EVM、TRON三链六场景族共90个候选验证案例；
- 执行一个三链公开端点探索探针并保留`blocked`结论；
- 为Bitcoin探针保存应用层请求/响应、环境、字段比较、manifest、对象哈希和root hash；
- 确认公共端点表面一致不能替代GT1至GT4真值。

### 当前限制

- 90个案例只是设计登记，其中81个尚未选定对象；
- 2个复用Bitcoin创世对象的案例存在真值争议；
- 没有任何样本达到`approved_for_validation`；
- 没有自控验证节点、已批准工具或具名独立复核；
- 本版本是验证准备基线，不是方法、工具、试点或生产发布。
