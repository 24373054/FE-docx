# 发布说明

## v3.0.0 — 2026-07-27

### 结构性修复

- 将00—10确立为唯一现行生产体系。
- 删除11—16平行版本目录；历史内容继续保留在Git历史中。
- 将原先只有一段摘要的00—09文件全部替换为具备范围、职责、详细控制、流程、场景、风险、记录和验收的完整文档。
- 将16份字段列表式“模板”替换为可直接填写、含字段属性、说明、附件、复核、示例和完整性检查的受控表单。
- 删除以文件数和行数代替质量的验收逻辑，增加内容结构、占位文本、重复内容、内部链接、追踪覆盖和禁止措辞检查。
- 建立需求—控制—测试—证据追踪目录和机器可读Schema。
- 建立生产发布、变更、历史案件影响和回滚要求。

### 监管与技术更新

- 纳入2026年6月1日起实施的CMA“一单一库”管理要求。
- 纳入CNAS司法鉴定机构认可的管理体系运行、内审、管理评审、能力活动和鉴定经历要求。
- 将北京市电子数据实验室功能区域和设备要求转化为建设与验收计划。
- 将电子数据完整性、在线提取、笔录、录像、写保护、可重现性和真实性审查转化为系统与SOP要求。
- 以Bitcoin、Ethereum/EVM、TRON官方协议文档作为方法依据入口。

### 兼容性与迁移

v3.0.0不保证旧目录路径兼容。任何外部链接、培训材料或自动化脚本引用旧11—16目录时，应更新到README中的单一权威路径。旧内容不得继续作为生产基线使用。
