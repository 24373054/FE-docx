# 分析工作台产品需求

## 1. 文件目的

定义分析人员和复核人员查看证据、运行受控分析、管理假设及解释结果的工作台。

工作台是受控视图，不是事实来源；图形、颜色和评分不能替代底层对象与方法。

## 2. 用户与模式

|模式|用户|主要动作|限制|
|---|---|---|---|
|采集核对|采集人员|核对原始对象、哈希和来源|不作分析结论|
|分析|链上分析员|复算、路径、时间线、假设|不可批准自己结果|
|盲复核|独立复核人|独立运行和比较差异|默认隐藏最终结论|
|质量只读|质量/审计|检查记录、版本和门禁|不能改技术结果|
|演示|获批说明人员|展示冻结报告对象|无实时扩展查询|

模式权限必须来自任务授权。

## 3. 信息架构

工作台至少分为：

- 任务与授权；
- 对象与来源；
- 原始/规范化字段；
- 交易与资产变化；
- 路径、时间线和图谱；
- 规则、参数与标签；
- 假设、反例与冲突；
- 方法运行与复核差异；
- 报告引用和受控导出；
- 审计和版本。

任何发现均可反向定位到对象。

## 4. 详细控制要求

|控制ID|主题|产品要求|阻断/降级|
|---|---|---|---|
|PRD-006-C001|证据引用面板|发现显示对象ID、字段/字节、来源、哈希和血缘|缺引用不得进入报告|
|PRD-006-C002|原始字段查看|只读显示原始字节/响应及编码，不做静默格式化|大对象按块读取并保留偏移|
|PRD-006-C003|标准化字段查看|并列显示原字段、映射规则、单位、时区和空值|映射未知时保留unknown|
|PRD-006-C004|资产变化账本|逐输入/输出/事件显示变化、费用和守恒检查|不平衡时标记冲突|
|PRD-006-C005|路径查询|固定种子、方向、深度、边类型、时间窗和停止条件|超范围/循环/推断边显式|
|PRD-006-C006|时间线|同时保存链时间、观察时间、系统时间和时区|禁止把区块时间当现实精确时间|
|PRD-006-C007|图谱视图|节点/边绑定对象与证据等级，可切换直接/推断关系|视觉接近不得生成关系|
|PRD-006-C008|候选关系|显示规则、置信、支持、反证和状态|默认不标记“已确认”|
|PRD-006-C009|规则解释|用可读语言展示规则来源、版本、条件和限制|黑盒规则隔离|
|PRD-006-C010|参数快照|每次运行冻结实际参数、默认来源和环境|只存当前全局配置不合格|
|PRD-006-C011|假设日志|创建、验证、否定和保留替代假设|禁止删除不利假设|
|PRD-006-C012|反例记录|反例绑定对象、适用规则和影响|报告不得只选支持证据|
|PRD-006-C013|来源冲突|字段级显示来源值、语义、时点和选择理由|未调和冲突阻断强结论|
|PRD-006-C014|人工备注|备注标明作者、时间、类型和引用，不改事实层|备注不能成为F1/F2|
|PRD-006-C015|复核差异|比较独立运行的输入、版本、参数和输出|P0差异未关闭保持blocked|
|PRD-006-C016|批注与签名|批注可追踪；数字签名仅在验证和密钥制度完成后启用|姓名图片不算签名|
|PRD-006-C017|导出受控快照|导出冻结筛选、视图、对象和版本并生成哈希|禁止导出实时可变链接代替证据|
|PRD-006-C018|性能降级策略|超过阈值时抽样/分页/聚合且明确提示|不得静默丢边或改结果|
|PRD-006-C019|大图分页|稳定排序、游标、总量/截断和恢复条件完整|分页变化触发重新冻结|
|PRD-006-C020|禁止黑盒总分|不显示无法解释的单一风险/追踪可信总分|供应商分数只能作外部声明|

全部控制当前为`not_implemented`。

## 5. 对象与字段视图

### 5.1 原始对象

原始视图显示：

- 对象ID和类型；
- 链、网络和来源；
- 文件/响应大小与SHA-256；
- 采集会话和时间；
- 只读字节、JSON或协议表示；
- 编码、压缩和解析状态；
- 完整性与异常。

不得在查看时改写换行、字段顺序或数值精度。

### 5.2 规范化对象

规范化表每行可展开：

`规范化字段 → 原字段 → 对象ID → 映射规则 → 版本 → 异常`

金额使用整数基础单位或精确十进制。

## 6. 路径与图谱

每次路径查询生成唯一运行ID。

最低输入：

- 种子对象；
- 链/网络；
- 时间/高度范围；
- 方向；
- 最大深度/节点/边；
- 允许边类型；
- 资产过滤；
- 推断规则；
- 停止条件。

结果区分：

- 直接协议关系；
- 经验证业务规则关系；
- 统计/启发式候选；
- 外部标签；
- 人工备注。

图谱截图只作为展示对象。

## 7. 时间与金额

时间必须标注来源：

- 区块/交易协议时间；
- 节点观察时间；
- 采集系统时间；
- 文件系统时间；
- 外部平台声明时间。

金额至少显示：

- 原始整数；
- 资产/合约标识；
- decimals/单位来源；
- 格式化值；
- 手续费或资源成本；
- 估值（若有）的价格来源和时点。

法币估值默认不是确定性链上事实。

## 8. 规则、标签与假设

规则卡包括：

- rule ID和版本；
- 适用链/协议；
- 来源和依据；
- 输入字段；
- 参数和默认值；
- 正向、边界、失败样本；
- 已知误报/漏报；
- 状态和批准；
- 输出证据等级。

标签卡包括来源许可和可争议机制。

假设卡同时列支持和反例。

## 9. 复核模式

盲复核流程：

1. 冻结执行包；
2. 分派未参与人员；
3. 隐藏执行人的最终判断；
4. 从对象和方法独立运行；
5. 生成独立输出；
6. 字段级比较；
7. 分类P0/P1/P2差异；
8. 记录共同讨论和最终处置；
9. 保留两套结果。

系统不得用“复核”按钮代替独立计算。

## 10. 性能与可用性边界

工作台在大图或大对象上可以：

- 分页；
- 延迟加载；
- 按获批规则聚合；
- 生成后台受控任务；
- 只展示前N项并标明总量/截断；
- 导出离线分析包。

任何降级都必须：

- 显示触发阈值；
- 保留原始查询；
- 不改变事实计数；
- 可在高资源环境重现；
- 写入运行和报告限制。

## 11. 导出与演示

导出包含：

- task/run ID；
- 视图类型；
- 过滤、排序、分页和布局；
- 对象/发现ID；
- 方法、规则和参数；
- 生成时间；
- 内容哈希；
- 水印和密级；
- 截断/聚合说明。

出庭或会议演示使用冻结快照，不临时调用不受控外部源。

## 12. 用户故事与验收示例

### 12.1 候选路径审查

作为复核人，我需要区分直接交易边与启发式候选边。

- [ ] 每条边显示关系类型和证据等级；
- [ ] 可定位到原始对象；
- [ ] 推断边显示规则、参数和反例；
- [ ] 关闭推断层后直接事实不变化；
- [ ] 导出保留筛选和图例；
- [ ] 报告不把候选关系写成确定身份。

### 12.2 大图降级

作为分析员，我需要在超过阈值时知道结果是否被截断。

- [ ] 页面显著提示阈值和截断；
- [ ] 显示已载入/总量或未知总量；
- [ ] 分页顺序稳定；
- [ ] 导出包含全部游标和过滤；
- [ ] 后台完整任务可核对；
- [ ] 截断结果不能用于“完整路径”结论。
